OM System OM-1 II：各焦点距離で写る範囲

OM System OM-1 IIのクロップ係数は2x（マイクロフォーサーズセンサー）です。そのため、レンズの写る範囲は、焦点距離に2xを掛けたフルサイズ用レンズと同じになります。OM System OM-1 IIに50 mmレンズを付けると、フルサイズの100 mm相当の範囲が写ります。

マウント：Micro Four Thirds

これらの焦点距離をライブで確かめるなら、ProspektにはOM System OM-1 IIが内蔵されています。焦点距離を選んでiPhoneを向けると、OM System OM-1 IIにそのレンズを付けたときに写る範囲が画面に表示されます。iPhoneアプリ、¥600の買い切りで、サブスクリプションはありません。

OM System OM-1 IIでフルサイズの定番焦点距離を再現

フルサイズのユーザーが言うこれらの焦点距離と同じ範囲を写すには、OM System OM-1 IIでは次の焦点距離を使います：

  • フルサイズの24 mmと同じ範囲を写すには、OM System OM-1 IIで12 mmを使います。
  • フルサイズの35 mmと同じ範囲を写すには、OM System OM-1 IIで18 mmを使います。
  • フルサイズの50 mmと同じ範囲を写すには、OM System OM-1 IIで25 mmを使います。
  • フルサイズの85 mmと同じ範囲を写すには、OM System OM-1 IIで42 mmを使います。
  • フルサイズの135 mmと同じ範囲を写すには、OM System OM-1 IIで68 mmを使います。

OM System OM-1 IIでの定番ズームレンズの写る範囲

  • OM System OM-1 IIに12-40 mmのズームレンズを付けると、フルサイズの24-80 mm相当の範囲が写り、水平画角は71.6°〜24.4°です。
  • OM System OM-1 IIに12-60 mmのズームレンズを付けると、フルサイズの24-120 mm相当の範囲が写り、水平画角は71.6°〜16.4°です。
  • OM System OM-1 IIに14-42 mmのズームレンズを付けると、フルサイズの28-84 mm相当の範囲が写り、水平画角は63.4°〜23.3°です。
  • OM System OM-1 IIに40-150 mmのズームレンズを付けると、フルサイズの80-300 mm相当の範囲が写り、水平画角は24.4°〜6.6°です。

OM System OM-1 IIでのポートレートの撮影距離

OM System OM-1 IIを縦位置に構え、被写体がフレームの高さの90%を占めるときの、被写体までの距離です。全身は身長1.8 mの人、バストアップは約0.5 mとしています。

  • OM System OM-1 IIで35 mmを使う場合：全身ポートレートは約4.0 m (13 ft)、バストアップは1.1 m (3.7 ft)。
  • OM System OM-1 IIで50 mmを使う場合：全身ポートレートは約5.8 m (19 ft)、バストアップは1.6 m (5.3 ft)。
  • OM System OM-1 IIで85 mmを使う場合：全身ポートレートは約9.8 m (32 ft)、バストアップは2.7 m (9.0 ft)。
  • OM System OM-1 IIで135 mmを使う場合：全身ポートレートは約15.6 m (51 ft)、バストアップは4.3 m (14 ft)。

よくある質問

OM System OM-1 IIで50 mmレンズはどう写りますか？

フルサイズの100 mm相当の範囲が写り、水平画角は19.6°です。

OM System OM-1 IIでフルサイズの50 mmと同じ範囲を写すレンズは？

約25 mmのレンズです。フルサイズの50 mm相当の範囲が写ります。

OM System OM-1 IIには35 mmと50 mmのどちらのレンズがいいですか？

OM System OM-1 IIでは、35 mmはフルサイズの70 mm相当の範囲が写り、3 m先で約1.5 × 1.1 mをカバーします。50 mmは100 mm相当で、約1.0 × 0.8 mです。広く写る35 mmは街歩き、旅行、室内に、画角の狭い50 mmはポートレートやディテールに向いています。フルサイズの定番35 mmと同じ写りにしたいなら、約18 mmを使ってください。

OM System OM-1 IIで85 mmレンズを使う場合、全身ポートレートはどのくらい離れて撮ればいいですか？

カメラを縦位置に構えて、被写体から約9.8 m (32 ft)です。身長1.8 mの人がフレームの高さの90%に収まります。バストアップなら約2.7 m (9.0 ft)離れてください。

OM System OM-1 IIで35 mmレンズを使うと、3 m先ではどのくらいの範囲が写りますか？

カメラを横位置に構えて、約1.5 × 1.1 m（幅 x 高さ）です。10 m先では約4.9 × 3.7 mが写ります。

レンズを買う前に、OM System OM-1 IIでこれらの焦点距離を確認できますか？

はい。iPhone用のProspektにはOM System OM-1 IIが内蔵されています。そのカメラを選んで焦点距離を決め、iPhoneを向ければ、写る範囲をライブで確認できます。

iPhoneでライブで確認

Prospektなら実際の景色で確かめられます。カメラボディと焦点距離を選んでiPhoneを向けると、そのレンズで写る範囲が画面に表示されます。¥600の買い切りで、サブスクリプションなし、オフラインで使えます。
