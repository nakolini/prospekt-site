OM System OM-1：各焦点距離で写る範囲

OM System OM-1のクロップ係数は2x（マイクロフォーサーズセンサー）です。そのため、レンズの写る範囲は、焦点距離に2xを掛けたフルサイズ用レンズと同じになります。OM System OM-1に50 mmレンズを付けると、フルサイズの100 mm相当の範囲が写ります。

マウント：Micro Four Thirds

OM System OM-1でフルサイズの定番焦点距離を再現

フルサイズのユーザーが言うこれらの焦点距離と同じ範囲を写すには、OM System OM-1では次の焦点距離を使います：

  • フルサイズの24 mmと同じ範囲を写すには、OM System OM-1で12 mmを使います。
  • フルサイズの35 mmと同じ範囲を写すには、OM System OM-1で18 mmを使います。
  • フルサイズの50 mmと同じ範囲を写すには、OM System OM-1で25 mmを使います。
  • フルサイズの85 mmと同じ範囲を写すには、OM System OM-1で42 mmを使います。
  • フルサイズの135 mmと同じ範囲を写すには、OM System OM-1で68 mmを使います。

よくある質問

OM System OM-1で50 mmレンズはどう写りますか？

フルサイズの100 mm相当の範囲が写り、水平画角は19.6°です。

OM System OM-1でフルサイズの50 mmと同じ範囲を写すレンズは？

約25 mmのレンズです。フルサイズの50 mm相当の範囲が写ります。

レンズを買う前に、OM System OM-1でこれらの焦点距離を確認できますか？

はい。iPhone用のProspektにはOM System OM-1が内蔵されています。そのカメラを選んで焦点距離を決め、iPhoneを向ければ、写る範囲をライブで確認できます。
