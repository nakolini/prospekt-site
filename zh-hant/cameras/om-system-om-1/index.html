OM System OM-1 上的經典全片幅焦段

要在 OM System OM-1 上得到全片幅使用者所說的這些焦距的取景，請使用：

  • 要得到全片幅 24 mm 的取景，在 OM System OM-1 上用 12 mm。
  • 要得到全片幅 35 mm 的取景，在 OM System OM-1 上用 18 mm。
  • 要得到全片幅 50 mm 的取景，在 OM System OM-1 上用 25 mm。
  • 要得到全片幅 85 mm 的取景，在 OM System OM-1 上用 42 mm。
  • 要得到全片幅 135 mm 的取景，在 OM System OM-1 上用 68 mm。

OM System OM-1 的人像拍攝距離

OM System OM-1 直拍時，要讓主體占畫面高度的 90%，需要離主體多遠。全身指身高 1.8 m 的人，頭肩約 0.5 m。

  • OM System OM-1 上用 35 mm：全身人像約 4.0 m (13 ft)，頭肩 1.1 m (3.7 ft)。
  • OM System OM-1 上用 50 mm：全身人像約 5.8 m (19 ft)，頭肩 1.6 m (5.3 ft)。
  • OM System OM-1 上用 85 mm：全身人像約 9.8 m (32 ft)，頭肩 2.7 m (9.0 ft)。
  • OM System OM-1 上用 135 mm：全身人像約 15.6 m (51 ft)，頭肩 4.3 m (14 ft)。

常見問題

50 mm 鏡頭在 OM System OM-1 上是什麼效果？

取景相當於全片幅的 100 mm，水平視角為 19.6°。

在 OM System OM-1 上用哪顆鏡頭能得到全片幅 50 mm 的效果？

大約 25 mm 的鏡頭。它的取景相當於全片幅的 50 mm。

在 OM System OM-1 上用 85 mm 鏡頭拍全身人像要站多遠？

直拍時離主體約 9.8 m (32 ft)。這樣身高 1.8 m 的人會占畫面高度的 90%。拍頭肩的話，站在約 2.7 m (9.0 ft) 處。

在 OM System OM-1 上，35 mm 鏡頭在 3 m 處能拍到多大範圍？

橫拿相機時約 1.5 × 1.1 m（寬 x 高）。在 10 m 處約為 4.9 × 3.7 m。

買鏡頭前，能看到這些焦距在 OM System OM-1 上的效果嗎？

可以。Prospekt iPhone 版內建了 OM System OM-1。選擇它，挑一個焦距，把手機對準場景，就能即時看到取景。
